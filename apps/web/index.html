Straight answers about what this is

The predictions are real.
They come from the ITU's reference implementation of P.533, verified numerically identical to a native build. Distances, bearings, MUF and the day/night behaviour all check out.
The sun is live.
Effective sunspot number from KC2G, refreshed hourly by our own service so your browser never contacts theirs. Every page says which source it used and how old it is.
You see SNR margin, not odds.
The engine's own "reliability" column is a known defect, so nothing shows it. The calibrated probability score in the design docs does not exist yet.
Storms are shown, not applied.
Kp and NOAA alerts are displayed with what they usually mean, but every prediction still assumes quiet geomagnetic conditions. When Kp is high, plan a lower fallback.
The full list of limits
Reliability. The engine's reliability output reads zero for every circuit tested and ignores the required-SNR input. It is an open defect, so nothing here displays it. What you see is SNR margin, which is verified responsive.
A-score. The calibrated probability described in the design docs depends on resolving that defect first, so it does not exist yet.
Reach maps are computed at 100 W into an isotropic antenna. Power is applied on top as an exact offset. Wire antennas carry their real elevation pattern, applied per map cell. Beams still use peak gain applied flat and read optimistic on paths whose take-off angle they do not favour. Coarse passes paint each sample across the block it stands for, so an early frame is a sketch.
Antenna model. A thin-wire model over perfect ground, not NEC. Pinned against the textbook constants it can be checked against (2.15 dBi free-space dipole, 5.15 quarter wave over ground). It reports directivity, so every gain figure is a lossless upper bound; where real ground costs you, the pages say so and the planner subtracts a stated estimate.
Space weather. Only the sunspot number reaches the engine, because it is the one input P.533 takes. Kp, solar flux and alerts are delivered and displayed, with guidance, but no prediction is bent by them. Making a storm change the numbers is a penalty layer scaled by geomagnetic latitude, which is the A-score's job.

Why it is built this way

On-device compute Our cost does not scale with users, so this stays free without a funding story.
Almost no server Static files plus one small scheduled job that fetches space weather, so NOAA and KC2G see a fixed 24 requests a day however many people use this.
Offline by construction Which matters for the emergency and field work this is aimed at, where there is no signal.
Nothing hides uncertainty Data age, model limits and known defects are shown rather than smoothed over.
