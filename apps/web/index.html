What is real here, and what is not.
Predictions come from the ITU's own reference implementation and are verified numerically identical to a native build of it. Distances, bearings, MUF and the diurnal behaviour all check out against reality.
The engine's reliability output is a known open defect — it reads zero for every circuit tested and ignores the required-SNR input — so nothing here displays it. What you see is SNR margin, which is verified responsive.
The A-score described in the design docs does not exist yet. It is meant to be a calibrated probability, and calibrating it depends on resolving that defect first.
Reach maps are computed for whatever transmitter you pick, at 100 W into an isotropic antenna. Your own power and antenna are applied on top as an exact offset. Antenna figures are peak gain applied flat, so beams read optimistic on paths whose take-off angle they do not favour. Coarse passes paint each sample across the block it stands for, so an early frame is a sketch until the finer passes land.
Solar activity is live: effective sunspot number from KC2G, refreshed hourly by our own service so your browser never contacts theirs. Every page states which source it used and how old it is, and falls back — to the snapshot published with the build, then to a clearly-labelled placeholder — rather than quietly reverting to a default sun.
What is still not modelled from live data: geomagnetic disturbance, flare absorption, and observed spot activity. Kp and alerts are fetched and shown but do not yet affect a prediction — that is what the A-score would add.

Why it is built this way

  • On-device compute means our cost does not scale with users, so this can stay free without a funding story.
  • Almost no server — static files plus one small scheduled worker that fetches space weather. It exists so that your browser never contacts NOAA or KC2G: their load is a fixed 24 requests a day no matter how many people use this.
  • Offline by construction, which matters for the emergency and field work this is aimed at, where there is no signal.
  • Nothing hides uncertainty: data age, model limits, and known defects are shown rather than smoothed over.
