HF propagation explorer

Real ITU-R P.533 predictions across 24 hours and nine HF frequencies. Pick a path, a season, and a solar activity level to see when each band opens.

Precomputed with the same WebAssembly engine HFKit runs on-device — live in-browser computation needs an 11 MB ionospheric data file per month, which cannot be embedded here. 100 W, isotropic antennas, residential noise, 24 dB required SNR in 3 kHz.

Cells show SNR margin in dB against the 24 dB requirement — how much signal you have to spare. Negative means short of it.
Isotropic antennas make this deliberately pessimistic: a real dipole or beam adds gain at both ends, shifting every cell upward. The shape — which band works when — is the useful part.
Engine . Not the A-score, which is a calibrated probability and does not exist yet.
